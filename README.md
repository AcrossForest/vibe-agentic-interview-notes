# Vibe Coding / Agentic Flow Interview Notes

A curated question bank for interviewing developers in the age of AI-assisted coding.

The questions target engineers who **use agentic CLI tools — Claude Code, Codex, and similar — as part of their daily workflow**. They are designed to probe practical fluency, trade-off awareness, and conceptual depth, rather than to test rote knowledge.

> There is **no canonical "correct answer"** in this bank. The attached reference answers are starting points for discussion, not constraints on it. Feedback and corrections are welcome.

## What's Inside

The bank is organized into six sections:

1. **Background Knowledge** — Foundational concepts (commands, skills, agents, MCP, sub-agents, agent teams).
2. **Detail Walkthrough** — Mechanics of `CLAUDE.md`, hooks, permission modes, `/compact`, plugins, ToolSearch.
3. **Workflow** — How to decompose features, debug, manage context, and operate agentic tools in a team setting.
4. **System Design (Open-Ended)** — Designing low-code agentic platforms, MCP gateways, multi-agent topologies, security review agents, and long-term memory mechanisms.
5. **Concepts & Philosophy (Open-Ended)** — Context simplicity, agent autonomy, TDD in agentic flows, code readability, and the future of programming as a profession.
6. **The Hidden Lore** — A few deeper questions on interruptible non-interactive sessions, the Superpowers flow, `/init`, and the "stdin/stdout/stderr" of an agent.
